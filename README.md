# Apple Product Knowledge Quiz

一个为 Apple 产品爱好者制作的中文知识测验网站。**1,866 道原创单选题，8 个知识领域，4 档难度**。题目、选项及解析由本项目编写，产品事实依据题目附带的 Apple 官方资料。

[进入测验](https://yunnre060214-sudo.github.io/Apple-Product-Knowledge-Quiz/?v=1.0.1) · [报告题目问题](https://github.com/yunnre060214-sudo/Apple-Product-Knowledge-Quiz/issues)

当前版本：**1.0.1**。优化手机端切题滚动：上一题、下一题保留阅读位置；从解析或答题卡切题时将新题题干带回视野。兼容 1.0.0 的未完成答题进度。

## 可以做什么

- 选择 10、20、50、100、200 题，或自定义 5 至 500 题。
- 选择入门、进阶、困难、专家或综合难度，可组合多个产品领域。
- 测验模式交卷后统一结算；练习模式逐题确认并查看解析。
- 随机抽题及打乱选项，同一份试卷没有重复题，优先抽取近期未答题。
- 按知识领域与难度分桶抽取，综合卷兼顾不同领域。
- 可设置不限时或每题 30、60、90 秒折算的全卷共享时限。
- 自动保存当前试卷、选项顺序、答案、标记、题号与截止时间，刷新后可以继续。
- 结算展示总分、正确率、用时、最长连对、难度加权分与各领域表现。
- 自动汇集错题及未答题，可重练本场错题或整个错题本，答对后自动移出。
- 查看最近 40 场记录与最近一场详细解析，导出含题目、答案、解析和来源的 Markdown 报告。
- 适配手机与桌面，支持深浅外观、键盘操作与减少动态效果偏好。

当筛选后的题库少于所选题量时，会明确显示并抽取全部可用题目。所有状态仅保存在当前浏览器的本地存储；更换设备、私密窗口或清除站点数据后不会跨设备恢复。网站没有账户、后台、统计 SDK 或答题记录上传。

## 题库

资料核对日期：**2026-10-15**。型号题均指明确指定的产品。后续软件更新、地区差异与官方规格修订，应以对应型号的官方资料为准。

| --- | ---: |
| iPhone | 774 |
| iPad | 558 |
| Mac | 233 |
| Apple 芯片 | 143 |
| Apple Watch | 81 |
| 音频与家居 | 33 |
| 系统与生态 | 24 |
| 产品历史 | 20 |

| 难度 | 题数 | 内容 |
| --- | ---: | --- |
| 入门 | 294 | 产品、接口、生物识别、基础功能 |
| 进阶 | 566 | 型号、芯片、代际、关键产品规格 |
| 困难 | 849 | 显示技术、传输标准、内存、配件兼容等 |
| 专家 | 157 | 双条件选型、规格比较、计算与实际情境 |

题库由三部分组成：

1. `src/catalog.json` 保存逐型号核对的产品事实及对应 Apple 技术规格地址。
2. `src/editorial.mjs` 保存芯片与部分产品事实、手工编写的概念题、应用情境和历史题。
3. `src/bank.mjs` 使用项目自写的题干、干扰项规则及解析，将事实组织为固定、可复现且有唯一答案的题库；比较题的干扰项必须至少满足其中一个条件并且违反另一个条件。同一题干只保留一次。

构建时生成 `dist/questions.json`，运行时不调用 AI，也不请求外部题库。题库公开可审阅，因此成绩用于自测，不作为防作弊考试认证。

总分为每题等权的百分制，未答计错。难度加权分另按入门、进阶、困难、专家分别赋予 1、2、3、4 分后折算，不影响总分。

## GitHub Pages 部署

首次使用，在仓库 **Settings → Pages → Build and deployment → Source** 选择 **GitHub Actions**。工作流为 `.github/workflows/pages.yml`，可在 Actions 页面运行 **Validate and deploy GitHub Pages**。

每次推送到 `main` 后，Actions 会依次执行逻辑与题库校验、静态构建、上传产物和发布。拉取请求只校验和构建，不发布。

工作流中的部署任务仅获取 `pages: write` 和 `id-token: write`，构建任务只读代码。Pages 的首次启用需要仓库管理员在设置中完成，默认的 `GITHUB_TOKEN` 无法代替此项初始设置。

## 本地开发

需要 Node.js 22 或更新版本，**没有第三方依赖，无须 npm install**。

```sh
npm test
npm run build
python3 -m http.server 8080 --directory dist
```

用浏览器访问 `http://localhost:8080`。通过 HTTP 提供网页才能加载题库与 ES 模块，直接双击 HTML 不适用。

## 维护

- 新增题目时提供官方来源、唯一正确答案、三个不成立的干扰项与有效解析。
- 兼容性题说明具体型号；区分物理接口和传输协议、内存和存储、显示尺寸口径、光学放大和变焦范围。
- 芯片题采用完整配置上限时明确说明，不能由核心数量或带宽倍数直接推断性能。
- 修改题库后运行 `npm test` 与 `npm run build`，将最新统计同步到本 README。
- 发布升级时同时修改 `package.json`、`src/engine.mjs`、HTML 与应用模块的资源版本参数、页脚版本和说明，防止新旧缓存混用。
- `/version.json` 可查看已部署版本、题目数量和资料核对日期。
